# FastHttpServer

Задача
+ Язык реализации C#
+ Простейший HTTP-сервер на сокетах Беркли (без использования готовых HTTP-библиотек и фреймворков).
+ Сервер должен уметь обработать POST запрос с JSON body в виде координат начала и конца пути на шахматной доске. Пример: { "from": "e2", "to": "h8" }
+ Сервер должен отвечать JSON-массивом, содержащий кратчайший путь шахматного коня по указанным координатам. Пример: ["e2", "f4", "g6", "h8"]
+ Если начальная и конечная клетки совпадают — вернуть массив с одной клеткой
+ Для работы с JSON можно использовать любую библиотеку

Примечание к реализации
 - платформа .NET 8.0
 - путь POST запроса не оговаривался, по этому можно использовать / или /get-path
 - для проверки работоспособности добавлена html страница доступная для GET запроса по пути / или /index.html
 - сервер прослушивает порт 8080

Сборка
git clone https://github.com/fas1100git/FastHttpServer.git
cd FastHttpServer
dotnet build
